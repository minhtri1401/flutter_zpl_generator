ZplRfidWrite

ZplRfidWrite class

Represents the ^RF (RFID Read/Write Format) sequence.

Encodes raw string data directly to the RFID chip's memory layer. This is used inside Zebra hardware capable of simultaneous ink-printing and RFID-radio encoding (such as the ZT411 RFID printer).
